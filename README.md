## Описание
Бэкенд. Парсинг отчетов студентов и их автоматическая проверка. Формат odt

## Установка и запуск

На момент написания приложения использовался Python 3.10.12

Перейдите в директорию с приложением и выполните

```
python3 -m venv venv
source venv/bin/activate
python3 -m pip install -r requirements.txt
```

И запустите сервер

```
python3 app/
```

после зайдите в бразуер по адресу 127.0.0.1/docs

## Дополнительно

Для изменения настроек сервера отредактируйте config.ini.
config.ini генерируется при первом запуске
